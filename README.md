# Frontend — SercoRiego Lite WMS

Aplicación web/PWA operativa de la maqueta. Conserva el diseño aprobado y utiliza módulos ES nativos.

### Capas
- `src/modules`: pantallas por dominio.
- `src/services`: persistencia, API futura, escáner, edición e inventario.
- `src/core`: router y configuración.
- `src/layout`: shell/navegación compartida.
- `src/components`: componentes UI compartidos.
- `src/data`: datos semilla para la maqueta.
- `styles`: estilos visuales originales.

KHAL PRINT 1.3 - INSTALADOR AUTONOMO PARA WINDOWS 64 BITS

1. Descomprime este ZIP en una carpeta.
2. Haz doble clic en INSTALAR_KHAL_PRINT.bat.
3. Espera el mensaje "KHAL PRINT INSTALADO CORRECTAMENTE".
4. Vuelve a Khal y pulsa "Ya lo instale - detectar Zebra".

IMPORTANTE
- NO necesitas instalar Python.
- NO necesitas pip.
- NO necesitas pywin32.
- NO necesitas configurar una IP fija de la impresora.
- Khal Print detecta las impresoras Zebra/ZDesigner/ZPL instaladas en ese Windows.
- Se instala para el usuario actual en %LOCALAPPDATA%\KhalPrint.
- Se configura para arrancar con Windows mediante HKCU (no requiere administrador normalmente).

Si Windows SmartScreen muestra una advertencia por tratarse de un ejecutable nuevo sin firma comercial, verifica que el archivo provenga del paquete oficial de Khal antes de ejecutarlo.

KHAL PRINT 1.1 · IMPRESION ZEBRA PARA KHAL WEB

- Se instala UNA sola vez en cada PC desde el que se imprimirá.
- Khal puede seguir alojado en Vercel/HTTPS.
- 127.0.0.1/localhost significa “este mismo computador”; NO es una IP fija de impresora.
- Khal consulta las impresoras Zebra/ZDesigner/ZPL instaladas en Windows y permite elegir cuál usar.
- La selección queda guardada localmente en ese navegador/PC.
- El trabajo se envía ZPL RAW; el PDF queda solo como respaldo.

INSTALACION
1. Confirma que Windows puede ver e imprimir una página/prueba con la Zebra.
2. Ejecuta INSTALAR_KHAL_PRINT.bat una vez.
3. En Khal > Etiquetas > Vista previa, espera “Zebra detectada” y pulsa Imprimir Zebra.
4. Si hay varias Zebra, elige una en el selector.

COMPATIBILIDAD
GC/GK/GX/ZD/ZT y otras colas cuyo nombre o driver Windows indique Zebra/ZDesigner/ZPL.
